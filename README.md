# Rumbo a México

Juego web de acción y aventura con estética de 16 bits. El protagonista recorre diez etapas desde Chile hasta México, enfrentándose a enemigos inspirados en personajes y tradiciones de Latinoamérica.

## Jugar

Abre `index.html` desde un servidor web estático. No requiere instalación ni proceso de compilación.

### Controles

- Flechas o `A`/`D`: caminar
- Flecha arriba, `W` o espacio: saltar
- `J` o `Z`: golpe
- `K` o `X`: patada
- `L` o `C`: terremoto
- `P` o `Esc`: pausa
- `M`: activar o silenciar el sonido

También incluye controles táctiles para dispositivos móviles.

## Estructura

- `index.html`: juego completo
- `assets/`: fondos y sprites optimizados para web
- `sonidos/nivelados/`: efectos de sonido
